# Task 4 – PCA & Unsupervised Clustering

This project focuses on dimensionality reduction and unsupervised clustering using the Wine dataset.

## Techniques Used

- Data Standardization
- Principal Component Analysis (PCA)
- PCA Scree Plot
- K-Means Clustering
- Elbow Method
- Silhouette Score Analysis
- DBSCAN Clustering
- Hierarchical Clustering
- Dendrogram
- 2D Cluster Visualizations

## Dataset

The Wine dataset from Scikit-learn was used for this analysis.

- Samples: 178
- Numerical Features: 13

## Results

- The first two principal components explain approximately 55.41% of the total variance.
- K-Means with 3 clusters achieved the highest Silhouette Score among the tested values of k.
- DBSCAN identified clusters as well as noise points.
- Hierarchical Clustering was visualized using a dendrogram.
